## 📌 Проблема

1. **Страх первого шага и эмоциональные сливы**: 70% начинающих инвесторов теряют депозит или выходят в минус в первые 3 месяца из-за эмоциональных решений — панических продаж на дне и покупки на пике эйфории (FOMO).
2. **Низкая эффективность традиционного обучения**: Академические лекции и статьи скучны (доходимость обучающих курсов редко превышает 10–15%).
3. **Бесчувственные демо-счета**: Обычные песочницы дают виртуальные деньги на текущем вялотекущем рынке, где новичку приходится неделями ждать результата без понимания рыночных циклов.

---

## 💡 Наше решение: «Инвест-Квест»

**«Инвест-Квест»** — это интерактивный рогалик/квест-тренажёр биржевого шторма, построенный на **реальных исторических данных российского фондового рынка**.

### Игровой цикл:
- 🎭 **Зашифрованная интрига (Анти-спойлер)**: Названия тикеров и года скрыты под псевдонимами («Зелёный Гигант», «Золотой Щит», «Цифровой Поисковик»). На оси времени отображаются только ходы («День 1», «День 2» ...), чтобы игрок оценивал ситуацию без предвзятости.
- 📉 **Живой свечной график Plotly**: График открывается строго по одной свече в день (будущее надежно скрыто), исключая пробелы выходных дней и визуализируя точки сделок (зеленые и красные маркеры).
- 📰 **ИИ-сводка дня и атмосфера «Пульса»**: На каждом шаге ИИ генерирует новостной фон и эмоциональные комментарии реальной биржевой толпы (паникёр 🐻 vs оптимист 🚀).
- 💬 **Интерактивный AI-аналитик**: Игрок может в любой момент хода задать вопрос аналитику («Почему падаем?», «Стоит ли усреднять?») и получить экспертную подсказку по риск-менеджменту.
- 🎯 **Принятие решений**: Игрок выбирает: `Купить на всё`, `Продать всё` или `Держать`.
- 🏆 **Грандиозный финал (День 10)**: Карты раскрываются! Игрок узнает реальную компанию (например, Сбербанк в феврале 2022 года), видит свой **PnL** против пассивного рынка (**Альфа**), получает персональный **AI-архетип инвестора** (*«Алмазные Руки»*, *«Снайпер Волатильности»*, *«Жертва Паники»*) и подробный разбор ошибок.

## 💼 Бизнес-ценность для экосистемы Т-Банка

1. **Виральный онбординг (User Acquisition)**: Геймифицированный формат карточного рогалика привлекает молодую аудиторию (Gen Z и миллениалов), превращая обучение в соревновательный азарт.
2. **Конверсия в открытие брокерского счета**: Игрок проживает острые исторические моменты без риска для реальных денег, избавляется от страха неизвестности и психологически готов к настоящим торгам.
3. **Продажа продуктов T-Capital (Monetization)**: На финальном экране под выявленный профиль риска пользователя автоматически подбирается сбалансированная корзина фондов Т-Банка (Золото `TGLD`, Вечный Портфель `TRUR`, Индекс Мосбиржи `TMOS`, Ликвидность `LQDT`) с симуляцией выставления ордера в **Sandbox API**.
4. **Раннее вовлечение в соцсеть «Пульс»**: Пользователь с первого дня учится фильтровать эмоциональный шум сообщества и ориентироваться на хладнокровный фундаментальный анализ.

## 🏛 Архитектура проекта

Проект спроектирован по модульному принципу без оверинжиниринга:

```
e:\T-invest\
├── data/
│   └── scenarios.json       # Локальный кэш сценариев (100% стабильность на демо)
├── .streamlit/
│   └── config.toml          # Фирменная темная тема Т-Банка (#FFDD2D, #121316)
├── data_loader.py           # Выгрузка свечей (Tinkoff Invest API SDK + офлайн кэш)
├── game_engine.py           # Игровое состояние, баланс, сделки, PnL и профилирование
├── ai_master.py             # LLM-генератор (OpenAI/DeepSeek + умный Fallback-режим)
├── app.py                   # Интерфейс Streamlit с Plotly-графикой и сессионным стейтом
├── requirements.txt         # Зависимости проекта
├── .env.example             # Шаблон конфигурации переменных окружения
└── README.md                # Документация проекта для жюри
```

### Модули:
- **`data_loader.py`**: Загружает сценарии из JSON или выгружает свежие дневные свечи через официальный `tinkoff-investments` SDK.
- **`game_engine.py`**: Управляет депозитом 100 000 ₽, рассчитывает стоимость портфеля, доходность в ₽ и %, стратегию Buy & Hold и присваивает архетипы инвестора.
- **`ai_master.py`**: Работает с любым OpenAI-совместимым провайдером. Имеет встроенный отказоустойчивый движок: если ключ не задан или нет интернета, приложение **не падает**, а выдает реалистичный контекстный контент.
- **`app.py`**: Одностраничное приложение на Streamlit с фирменной стилизацией Т-Банка, поддержкой интерактивного вопрос-ответного диалога с ментором и симуляцией брокерского ордера.

## 🚀 Быстрый запуск

### 1. Клонирование репозитория и переход в папку
```bash
cd e:\T-invest
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка окружения (Опционально)
Скопируйте файл `.env.example` в `.env`:
```bash
copy .env.example .env
```
В файле `.env` можно указать свои ключи:
```env
# Ключ OpenAI или совместимого сервиса (DeepSeek, OpenRouter, vLLM)
OPENAI_API_KEY=your_key_here
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini

# Токен Tinkoff Invest API (для выгрузки новых исторических данных)
T_INVEST_TOKEN=
```
> **Важно**: Приложение полностью работоспособно **без API-ключей** благодаря встроенному локальному демо-движку и кэшу исторических сценариев!

### 4. Запуск приложения
```bash
py -m streamlit run app.py
```
*(Или `streamlit run app.py`)*

Интерфейс откроется в браузере: **`http://localhost:8501`**
